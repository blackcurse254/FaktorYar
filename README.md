# فاکتوریار (Faktoryar)

فاکتورساز آفلاین و سبک برای صاحبان مشاغل ساختمانی (نقاشی، برق‌کاری، لوله‌کشی، بنایی و ...).
تمام داده‌ها فقط در `localStorage` مرورگر کاربر ذخیره می‌شود — بدون سرور، بدون حساب کاربری.

## ساختار پروژه

```
index.html   اسکلت اصلی برنامه (HTML)
app.js       کنترلر برنامه — رندر صفحات، فرم‌ها، مدیریت وضعیت
app.css      استایل کامپوننت‌ها (دکمه، کارت، جدول، مودال، ...)
theme.css    سیستم طراحی پایه — رنگ‌ها/توکن‌های حالت روشن و تیره
core.js      توابع کمکی: تقویم جلالی، فرمت اعداد فارسی، ذخیره‌سازی
data.js      داده‌های ثابت: لیست اصناف، آیکون‌های SVG، قیمت‌نامه پیش‌فرض
legacy/      نسخه‌ی قدیمی و مستقل (تک‌فایلی) که قبل از این بازسازی وجود داشت — فقط برای مرجع نگه داشته شده و در برنامه‌ی فعلی استفاده نمی‌شود
```

## این تغییرات نسبت به فایل‌های اولیه انجام شد

فایل‌های آپلودشده در واقع دو نسخه‌ی جدا از هم بودند، نه یک پروژه‌ی هماهنگ:

- `index.html` نسخه‌ی قدیمی و تک‌فایلی بود (استایل و دیتای اموجی‌محور داخل خودش).
- `core.js` و `data.js` یک لایه‌ی جدید و پیشرفته‌تر بودند (تقویم جلالی، آیکون SVG بدون اموجی، ذخیره‌سازی با migration) که هنوز به هیچ HTML متصل نشده بود.
- `theme.css` در حین آپلود خراب شده بود — تمام کولون‌های بعد از نام property و برخی سلکتورها (`::before`, `::-webkit-scrollbar` و ...) حذف شده بودند و فایل به‌کلی نامعتبر بود.

کارهای انجام‌شده:

1. **بازسازی `theme.css`** با سینتکس معتبر CSS، بدون تغییر در نام یا مقدار متغیرها.
2. **ساخت `index.html` تازه** که واقعاً از `core.js` + `data.js` + `theme.css` استفاده می‌کند (نه نسخه‌ی قدیمی جدا).
3. **افزودن `app.js` و `app.css`** — چون لایه‌ی دیتا/توکن به‌تنهایی UI کامل نمی‌سازد، یک کنترلر برنامه و استایل کامپوننت روی همان توکن‌های `theme.css` نوشته شد.
4. تست کامل با مرورگر headless: ساخت/ویرایش/حذف مشتری، افزودن قلم به قیمت‌نامه، ساخت فاکتور با اقلام از قیمت‌نامه و اقلام دستی، محاسبه‌ی تخفیف/مالیات، ذخیره در localStorage، پیش‌نمایش چاپی — همه بدون خطا اجرا شدند.

## امکانات

- داشبورد با نمودار درآمد ۶ ماه اخیر (Chart.js)
- ساخت فاکتور بر اساس صنف، با انتخاب قلم از قیمت‌نامه یا افزودن دستی
- مدیریت مشتریان و قیمت‌نامه‌ی هر صنف
- تاریخ شمسی، اعداد فارسی، مبلغ به حروف
- خروجی PDF (jsPDF + html2canvas) و چاپ مستقیم
- پشتیبان‌گیری/بازیابی JSON و پاک‌سازی کامل داده‌ها
- حالت روشن (کاغذ کرافت) و تیره (کارگاه فلزی)

## اجرا

نیازی به build یا نصب پکیج نیست. کافی است `index.html` را از طریق یک وب‌سرور محلی باز کنید (به‌خاطر `fetch`/`localStorage`، باز کردن مستقیم فایل با `file://` در برخی مرورگرها محدودیت دارد):

```bash
npx serve .
# یا
python3 -m http.server 8080
```

سپس آدرس را باز کنید: `http://localhost:8080`

## استقرار (GitHub Pages)

1. این پوشه را در یک ریپازیتوری گیت‌هاب push کنید.
2. در تنظیمات ریپو → Pages → Source را روی شاخه‌ی `main` (پوشه‌ی ریشه) بگذارید.
3. آدرس منتشرشده `index.html` را مستقیماً سرو می‌کند — چون پروژه کاملاً استاتیک است، نیاز به هیچ تنظیم دیگری نیست.

## نکات فنی

- کتابخانه‌های Chart.js، html2canvas و jsPDF از CDN بارگذاری می‌شوند؛ در محیط بدون اینترنت (یا با مسدودسازی CDN) فقط نمودار داشبورد و خروجی PDF غیرفعال می‌شوند — بقیه‌ی برنامه (فاکتور، مشتریان، قیمت‌نامه، چاپ مرورگر) بدون وابستگی به شبکه کار می‌کند.
- تمام داده‌ها در `localStorage` با کلید `faktoryar.db` ذخیره می‌شود؛ برای انتقال بین دستگاه‌ها از «پشتیبان‌گیری» در تنظیمات استفاده کنید.
